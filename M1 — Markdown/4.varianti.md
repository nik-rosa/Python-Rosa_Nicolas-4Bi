# Le varianti di Markdown a confronto

Markdown esiste in diverse varianti. In questo documento vengono confrontati il Markdown originale, CommonMark e GitHub Flavored Markdown (GFM), evidenziando le principali differenze.

## Tabella di confronto

| Costrutto | Markdown originale | CommonMark | GitHub Flavored Markdown |
| :--- | :---: | :---: | :---: |
| Blocchi di codice recintati | No | Sì | Sì |
| Tabelle | No | No | Sì |
| Caselle di spunta | No | No | Sì |
| Testo barrato | No | No | Sì |
| Collegamenti automatici | No | Parziale | Sì |
| Note a piè di pagina | No | No | Sì |

## Esempi delle estensioni di GitHub Flavored Markdown

### Caselle di spunta

- [x] Installare Visual Studio Code.
- [x] Installare Git.
- [ ] Installare JDK 17.
- [ ] Configurare il repository GitHub.
- [ ] Accedere al server Jupyter.
- [ ] Controllare l'anteprima prima del commit.

### Testo barrato

La versione ~~1.8~~ è stata sostituita dalla versione **1.9** di Visual Studio Code.

### Collegamento automatico

https://commonmark.org

Su GitHub questo indirizzo diventa automaticamente un collegamento cliccabile.

## Quale variante usare per il corso

Per le consegne del corso conviene usare **GitHub Flavored Markdown** perché è completamente supportato da GitHub e offre funzionalità aggiuntive molto utili, come tabelle, caselle di spunta, testo barrato, collegamenti automatici e note a piè di pagina. Queste estensioni rendono i documenti più chiari e più facili da leggere.

Nell'anteprima di Visual Studio Code le tabelle, il testo barrato e le caselle di spunta vengono visualizzati correttamente, in modo molto simile a GitHub. Su GitHub, inoltre, il collegamento automatico viene trasformato in un link cliccabile e le note a piè di pagina sono gestite completamente.

Se questo stesso file viene aperto con uno strumento che implementa solo CommonMark, alcune estensioni di GitHub Flavored Markdown potrebbero non essere riconosciute. Le caselle di spunta potrebbero apparire come semplice testo, il testo barrato potrebbe non essere visualizzato correttamente e le note a piè di pagina potrebbero essere ignorate.

# Esercizio 2 — Istruzioni di compilazione con elenchi, comandi e citazioni

1. Clona il repository.
2. Apri la cartella `src/`.
3. Compila i file.

```bash
mkdir bin
javac -d bin src/MediaVoti.java
```

4. Esegui il programma.

```bash
java -cp bin MediaVoti
```

5. Controlla il risultato.

> Error: could not find Java runtime.

# Scheda Personale di Postazione

## Hardware

La postazione di laboratorio è un pc desktop configurato per supportare applicazioni di programmazione come VS code, jupyter. La macchina è dotata di un processore Intel core i5-4590 3.30GHz e dispone di 8 GB DDR3 di memoria RAM, garantendo **affidabilità** durante la compilazione del codice.

Il sistema operativo installato è Windows 11 Pro Education, costantemente aggiornato con le ultime patch di sicurezza d'istituto. Per l'archiviazione dei dati e dei progetti locali viene utilizzato un disco a stato solido da 233 GB.

## Software installato

L'ambiente di sviluppo principale è costituito da Visual Studio Code Web integrato direttamente nel browser all'interno dell'ambiente cloud, aggiornato alla versione 1.139x. Questa configurazione include già tutte le estensioni ufficiali necessarie per la gestione dei linguaggi di programmazione utilizzati in aula, senza richiedere installazioni locali sulla macchina.

### Controllo versione

Come sistema di controllo del codice viene utilizzato Git nella versione 2.55x. Questo strumento consente di tracciare le modifiche ai file del progetto e di sincronizzare agevolmente il lavoro con i repository remoti in modo sicuro.


## Credenziali di accesso

Per accedere alle risorse del corso è necessario utilizzare l'account **GitHub** personale, che deve essere preventivamente associato all'organizzazione del laboratorio. Tramite questa identità digitale è possibile condividere il repository cosi che il prof possa vedere i progetti e gli esercizi.

Il secondo servizio fondamentale è rappresentato dal **Jupyter server** d'istituto, raggiungibile tramite l'indirizzo web fornito dal docente. L'autenticazione a questa piattaforma avviene tramite il sistema di Single Sign-On della scuola, senza la necessità di memorizzare nuove password locali.
